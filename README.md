# TypeScript শেখার নোট ও উদাহরণ

এই repository-তে TypeScript-এর গুরুত্বপূর্ণ type system ধারণা নিয়ে বাংলা
ব্যাখ্যা এবং ব্যবহারিক code example রয়েছে। এটি TypeScript-এর type declaration,
type checking ও সাধারণ programming pattern বুঝতে শেখার সহায়ক উপকরণ।

## বিষয়বস্তু

- [Type Narrowing](./type-narrowing.md) — `typeof`, `instanceof` ও `in`
  operator দিয়ে union type-এর নির্দিষ্ট type শনাক্ত করা।
- [Type বনাম Interface](./type-vs-interface.md) — `type` alias ও `interface`-এর
  পার্থক্য, বৈশিষ্ট্য এবং কোন পরিস্থিতিতে কোনটি বেছে নিতে হবে।
- [সমাধান ও উদাহরণ](./solutions.ts) — optional parameter, union type, tuple,
  generic, interface, class inheritance এবং asynchronous function-সহ বিভিন্ন
  TypeScript উদাহরণ।
